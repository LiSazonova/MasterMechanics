# Master Mechanics

Landing page for an auto repair shop in Odesa. React + Vite, three languages (EN / UA / RU), online booking via n8n webhook.

**Live:** [https://master-mechanics-yxq6.vercel.app](https://master-mechanics-yxq6.vercel.app)

## Stack

React · Vite · JavaScript · Custom i18n · n8n Webhooks · Responsive Design · Vercel

## Run locally

```bash
npm install
npm run dev
```

Optional: copy `.env.example` → `.env` and set `VITE_SITE_URL` if it differs from production.

## Build

```bash
npm run build
npm run preview
```

## Deploy (Vercel)

- Build: `npm run build`
- Output: `dist`
- Env: `VITE_SITE_URL=https://master-mechanics-yxq6.vercel.app`
